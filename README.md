# 🔐 VaultLite – File Encryption and Decryption Tool

**A Secure File Encryption and Decryption Application**

## 📌 About the Project

VaultLite is a file encryption and decryption tool designed to help users protect their files and understand the importance of data security.

The application provides functionality for encrypting files and decrypting them when access is required.

## ✨ Features

- 🔒 File Encryption
- 🔓 File Decryption
- 🛡️ Data Privacy and Protection
- 💻 Simple and User-Friendly Interface
- ⚡ JavaScript-Based Implementation
- 🧪 Testing Support

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/rublinjoej-coder/file-encryption-and-decryption-tool.git
```

### 2. Open the Project

```bash
cd file-encryption-and-decryption-tool
```

### 3. Run the Application

Open the project in Visual Studio Code.

If your server uses Node.js, run:

```bash
node server.js
```

Open the application in your browser using the local URL displayed by your server.

## 🎯 Project Objective

The main objective of VaultLite is to demonstrate file security through encryption and decryption techniques while providing a simple interface for users.
