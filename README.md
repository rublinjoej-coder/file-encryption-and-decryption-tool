### Quick Start
You have **Node.js** already installed. Run the included zero-dependency server:
```powershell
node server.js
```
Then visit **`http://localhost:3000`** in your browser.

Alternatively:
- Open in VS Code and click **"Go Live"** (with Live Server extension).
- Or double-click `VaultLite/index.html` to open directly.
