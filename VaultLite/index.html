Security Architecture & Cryptographic Specs

How VaultLite protects your sensitive files with zero-knowledge, local-first cryptography.

Authenticated Encryption

Uses AES-256-GCM (Galois/Counter Mode). In addition to encrypting data, it generates a 128-bit authentication tag to ensure any file tampering or corruption is instantly detected.

Hardened Key Derivation

Employs PBKDF2 with HMAC-SHA-256 with 300,000 iterations and a unique 128-bit cryptographically secure random salt to defend against dictionary and rainbow-table attacks.

Zero Server Exposure

No backend, no remote API calls, no databases, and no cloud analytics. All cryptographic calculations take place in your browser sandbox using the native crypto.subtle engine.

Technical Cryptographic Specifications

Encryption Algorithm AES-256-GCM (Galois/Counter Mode)
Key Size 256 bits (32 bytes)
Authentication Tag 128 bits (16 bytes, verified automatically)
Key Derivation Function PBKDF2-HMAC-SHA-256
PBKDF2 Iterations 300,000 rounds
Salt Length 16 bytes (128 bits) via crypto.getRandomValues()
Initialization Vector (IV) 12 bytes (96 bits) unique per file via crypto.getRandomValues()
File Container Format .sfe (Secure File Encryption, binary format v1)

First-Time User Instructions

  1. To Encrypt: Drag in any file, enter a strong passphrase, confirm it, and click Encrypt File. Save the generated .sfe file.
  2. Keep your passphrase safe: There is no password recovery or "Forgot Password" feature. If you lose your passphrase, the data cannot be restored.
  3. To Decrypt: Switch to the Decrypt tab, upload the .sfe file, type the original passphrase, and click Decrypt File.
  4. Verification: The application automatically verifies file integrity and restores the exact filename and file type.

Security Limitations & Disclaimer

VaultLite provides industry-standard client-side encryption. However, no software is unconditionally unbreakable. Security depends directly on the strength and entropy of the user's chosen passphrase. The application runs within the security boundaries of your web browser and operating system; compromised host devices, keyloggers, or malicious browser extensions could expose secrets in memory.
